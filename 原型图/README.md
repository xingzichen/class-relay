# 家校日常小程序 Web 原型

本轮版本：2026-09-09。直接双击 `index.html`；须保留同目录 `app.css`、`app.js`。也可在项目根目录运行：

```sh
python3 -m http.server 8080 --directory 原型图
```

然后访问 `http://127.0.0.1:8080/`。页面资源全部本地加载，可离线使用，刷新重置全部模拟状态。

## 已可操作的演示

- 发布：普通通知截止可选、默认不要求确认；采集/待办截止必填；组合范围去重；阅读、处理、提醒分开预览，类型驱动详情回执。
- 活动：原生参加/不参加与数量回填，多孩子独立；志愿者可无账号，由关联家长代报名、候补、退出及替补确认；腾讯文档自报待管理员核验，实际链接仅演示配置，未打开真实表单。
- 日程：课程委托包含发布；临时串课后保留已完成准备，更换材料且显式重新确认才开启新轮次；值日换人后原家庭可见最小告知。
- 财务：复核入账与公示发布分开；公示保留完整旧版本直至审核切换；自报已交只暂停催款；每日两次上限及两小时间隔可用模拟时钟检查，固定“如果已交款请忽略”。
- 交接：盘点未完成事项、知识、活动、财务和旧授权 → 切换李委员接收 → 切换老师或系统管理员批准。生效后沈委员失去旧管理权但保留家长视角，李委员承担维护；账本和历史保留。
- 维护：任务/知识/活动负责人指派、知识有效期与来源版本、家庭提醒偏好、正式授权的独立线下核验记录、物资认领领取归还。

## 边界

班级、人员、金额和日期全部虚构；原型只展示一个示例班级与家庭，身份切换是评审工具，不是生产权限认证。未连接 CloudBase、微信订阅或腾讯文档服务，不发送消息、不收付款、不写真实账本。AI 为本地预设示例，没有接入真实模型。

跨班/多用户并发、真正的额度事务、角色及文件鉴权、实时表单同步和账务核对，仍按方案在正式 CloudBase 实现与验收。志愿者新增称呼仅演示，跨家庭同名合并及身份核验仍需管理员流程。

## 浏览器回归检查

`tests/interactions.cjs` 使用 Playwright 与独立临时 Chrome 配置，读取本地页面。环境中提供 Playwright 后运行：

```sh
node 原型图/tests/interactions.cjs
```

若 Playwright 来自单独的运行库，设置 `NODE_PATH` 指向对应 `node_modules`。检查覆盖发布类型与组合范围、报名去重/候补、课程完成轮次、财务异步状态、限频、交接与旧授权撤销，以及 320/390/736 像素明暗布局。截图存系统临时目录，不提交真实家庭资料。
