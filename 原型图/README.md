# 家校日常小程序 Web 原型

双击 `index.html`，或在当前项目根目录执行：

```sh
python3 -m http.server 8080 --directory 原型图
```

然后访问 `http://127.0.0.1:8080/`。

这是用于评审需求和交互流程的静态原型，数据均为虚构示例。页面不会连接腾讯云开发、发送微信订阅消息、打开真实腾讯文档、收付款或写入真实账本；刷新页面会重置演示状态。

可切换普通家长、老师、家委会和系统管理员视角，查看任务与待办、课程和值日临时调整、费用公示、孩子关联审批、知识库和公共事项问答。问答使用预设演示回复，不代表生产 AI 模型或安全策略已经接入。

页面主体可离线使用；图标通过公开 CDN 加载，离线时不影响文字、页面导航和模拟交互。
