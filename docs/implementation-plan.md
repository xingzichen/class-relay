# 实施计划与验收

版本 0.6 · 2026-09-10 · 当前已完成 P0-01/P0-02 工程与契约；P0-03 已关联新微信云环境，身份探针已部署，参数与配置问题待定位，客户端未验收；P0-04 事务适配层本地通过，整包开发中。以下仍是完整业务开发与验收基准。

执行层细分见[开发计划](development-plan.md)：将下列 P0—P6 拆为 69 个开发包，每包定义前置依赖、交付物、单元测试和阶段验证；[开发提示词](development-prompts.md)提供一一对应的完整执行提示。本文继续作为阶段与 A/B 验收场景的基准，细分计划不替代或改写这些预期。

## 1. 分期

| 阶段 | 交付 | 进入下一阶段的条件 |
|---|---|---|
| P0 平台验证 | 主体/订阅模板、CloudBase 环境/AppID/权限、事务/定时恢复、模型/日志/预算、真实文档跳转及财务经办复核安排 | 真实接口/后台/真机证据，未具备能力明确回退 |
| P1 身份与授权 | 四角色、管理员委托、学生/家庭、关联覆盖、成人参与人及代填模型、日程/财务/正式授权能力目录 | 全局与班级区分、禁止自审/自提权、至少一名关联家长作为运营目标，异常不伪造绑定 |
| P2 通知、日程与回执 | 模板、类型与截止、阅读/处理分离、公共/定向权限、最小变更告知、课程/值日和回执轮次、家庭偏好、日总预算 | 完成/移出停催但必要变更可告知；普通≤2、变更≤2、总计≤4、两小时间隔及免打扰；恢复不刷屏 |
| P3 采集、活动与财务 | 原生答复/腾讯文档、代报名/名额/候补、活动取消、正式授权核验、共享催办、异步收款/复核/公示、催款≤2与忽略提示 | 原生与自报来源不同；名额不虚报；取消不伪造退款；账本、公示及核对可追溯 |
| P4 知识、AI 与维护交接 | 公共资料分类、事项身份、授权检索和缓存、owner 维护、未完成事项/知识/活动/财务交接及旧授权撤销 | AI01—AI21 与安全用例通过；交接接收不提权，生效后旧权失效且历史保留 |
| P5 单班试用 | 备份恢复、运营配置、真实家庭试用、离班资料流程、前述模块联合验收 | A01—A30、B01—B15/B17—B20、S01—S15、F10/F11、AI01—AI21 通过，平台限制明确 |
| P6 已采纳后续交付 | 轻量物资认领、领取、归还、保管分工和关联支出；在试用稳定后实现 | B16 通过；必须跟踪交付，不能以 P5 完成宣称全部采纳需求已实现 |

产品聚焦公共可复用事项；反馈受理、冲突调解和敏感个案不在实施范围。费用模块是用户要求的主方案范围，不作为长期搁置的可选插件。上述分期仅为实现先后；AI 与采集同样属于最终交付范围。

## 3. 端到端验收场景

以下均是待执行场景，不是本次文档编写已完成的测试。

| ID | 操作场景 | 预期 |
|---|---|---|
| A01 | 加入时选择老师＋普通家长 | 保留两个申请；老师未授权前无管理权，批准后本班权限生效 |
| A02 | 新用户勾选系统管理员或伪造角色字段 | 不会自助获得最高权限；首位管理员仅初始化绑定 |
| A03 | 老师将家长设为本班任务管理员 | 仅授予所选能力，不能管其他班、授予角色或审批孩子关联；撤销即时失效 |
| A04 | A 班老师进入 B 班任意对象 URL | 没有 B 班授权即拒绝；切换界面身份不能绕过 |
| A05 | 老师和家委会同时改同一学生，另有同名学生 | 检测编辑冲突，按 ID 区分同名，不覆盖错误孩子 |
| A06 | 妈妈、爸爸、奶奶申请同一孩子，妈妈还有另一孩子 | 支持多对多，称谓分别保存，未审批不收孩子通知 |
| A07 | 家委会为自己申请孩子并尝试自审；两人并发审批 | 自审被拒绝；并发只有一个有效终态，审批留痕 |
| A08 | 撤销关系后点击旧微信通知卡片 | 重新鉴权拒绝访问，取消未来提醒；历史外发不伪装为可撤回 |
| A09 | 女生＋自建群组＋学生多选有重叠 | 学生并集去重，未填写性别不混入女生；预览人数正确 |
| A10 | 发布后改群组、添加亲属或移出学生 | 群组不静默改变旧目标；新亲属加入开放事项；移出学生停止私有任务访问/催办，公共阅读按资格保留，最小变更告知单独授权 |
| A11 | 一个孩子有三位亲属，另一个没有亲属 | 三人建收件关系；无亲属孩子保留任务并标待补齐，不计通知成功 |
| A12 | 打开腾讯文档后直接返回；随后自报完成并被退回 | 打开不算提交；自报注明来源，退回恢复未完成；同源待办联动且不重复催 |
| A13 | 默认按学生模式妈妈点完成；切到逐亲属模式重复测试 | 默认停止该孩子所有亲属催办；逐亲属只完成妈妈实例 |
| A14 | 一个家长两个目标孩子，仅完成其中一个 | 另一孩子仍待办；同一时点外发可合并，完成实例不合并 |
| A15 | 截止前计划重合、夜间、超过日上限 | 合并、顺延或跳过符合策略，不在截止后补发旧催办 |
| A16 | 取消/修订截止/重新确认与发送并发 | 旧计划失效，重新确认新轮次，旧回执保留；详情显示最新状态 |
| A17 | 明确失败、发送超时、发送后云函数超时/实例回收、定时重复触发 | 退避有上限；未知结果不盲目重发；队列可恢复且无集中补发 |
| A18 | 家委会解释与老师原通知矛盾、老师随后修订 | 不以权限等级猜事实；来源矛盾时暂不下结论且无反馈工单，修订后原文/索引/引用同步更新 |
| A19 | 普通家长问另一孩子定向通知并注入越权指令 | 检索前过滤，模型与来源下载均不能得到他人数据 |
| A20 | 模型不可用或知识无答案 | 原文和任务仍可使用，无依据明确说明，不自行审批/发布/完成 |
| A21 | 真机跨运营商访问和新环境恢复备份 | 云函数调用、云存储、微信云调用实际可用；回档集合/文件清单/权限/回执/账本相符后再启外发 |
| A22 | 同一孩子两位亲属分别声明已缴，重复上传凭证 | 不因声明增加实收；核对真实交易和分配，避免重复入账 |
| A23 | 40 人×50 元，收齐 2,000 元，打扫 600 元、布置 300 元、退款 100 元 | 账面余额 1,000 元；同时显示退款归属和调整后家庭缴费状态 |
| A24 | 已入账支出金额记错、家委会尝试直接覆盖或自复核 | 禁止覆盖和自复核；冲正/重记形成完整链路，公示生成新版本 |
| A25 | 家长访问费用页与凭证，跨班或猜原图 URL | 展示本班公示的所有孩子缴费状态与金额，自家缴费可查业务明细；跨班拒绝，原凭证受控 |
| A26 | 实际账户余额与账本不符、费用项目结项仍有结余 | 显示差异和原因，不虚构已对账；结余处置记退款/结转及审核记录 |
| A27 | 客户端直连核心集合、跨路径上传、凭 fileID 读他人原始凭证 | 均被拒绝；临时链接有效期和权限撤销边界明确 |
| A28 | 普通客户端调用内部调度/公示函数、定时函数复用请求实例 | 内部入口拒绝客户端；不得复用上次家长微信身份 |
| A29 | 超单事务容量分批展开，中断重试且随后取消 | 无重复实例；旧批次不继续催办；新建最小变更告知另行鉴权 |
| A30 | 财务入账后生成快照，随后审核发布 | 生成/待发布期间保持完整旧版本及截止；审核发布后全量切换同一修订 |

AI 上线还必须通过[AI01—AI21 语气与边界用例](ai-response-policy.md)，日程上线通过[S01—S15](schedules.md)。

未来若启用小程序支付，追加测试：伪造客户端成功不入账、回调签名/商户/AppID/金额不符拒绝、重复回调只入账一次、查单补偿不重复入账、退款失败不扣余额、重启后支付/退款状态一致。

## 5. 协作与一致性验收

| ID | 必须通过的业务验收 |
|---|---|
| B01 | 全局管理员未逐班入班仍可管理；不能代亲属回执，自审/自复核仍被拒绝 |
| B02 | 公共说明非目标家庭可读但无回执；私有任务移出后不可读，只保留授权的最小变更告知 |
| B03 | 普通通知无截止可发布、默认无需确认；采集/待办必须有截止；类型进入实际发布记录 |
| B04 | 女生＋合唱队＋个人多选按学生并集去重；预览分别列阅读、处理、提醒及无接收人 |
| B05 | 已完成准备后仅移课保留完成；换人不复制旧人完成；重新确认才增加轮次 |
| B06 | 未注册/未订阅成人由有效关联家长代报名；名额属于实际成人，提醒给代填人，取消关联后需重新指定接收人 |
| B07 | 双孩子及两亲属重复报同一成人提示核验；原生满额进候补；外部自报不自动占名额，人工核验后确认 |
| B08 | 原生参加/不参加/数量按孩子提交修改，已答复不催；普通确认不产生正式监护授权 |
| B09 | 活动取消统一停止报名、待办与未来执行，旧家庭可见必要告知；已收资金待处置，不显示自动已退款 |
| B10 | 同接收人跨班跨项目手动/自动催款每天最多两次且有忽略提示；UNKNOWN 重试不绕过上限，已核实未公示、自报待核对暂停催款 |
| B11 | 跨任务普通外发最多两次、变更告知最多两次、总计最多四次、两小时间隔与免打扰有效，站内仍可用 |
| B12 | 交接未接收不能生效；有权者生效后任务/知识/活动转维护人、列明旧管理授权立即撤销，原作者/层级/回执/账本/家庭关系保留 |
| B13 | 财务交接保留未核对款项、差异、公示历史及独立复核人；不能把交接完成当作资金已核对 |
| B14 | 两个不同活动时间不同不误判 AI 冲突，同活动正式修订使旧引用失效 |
| B15 | 离班只申请本家庭资料，无法恢复全班公示；基础升年级延续与转班/毕业分别处理 |
| B16 | 物资认领/领取/归还按数量和责任人留事件，重复领取不超量；关联支出不重复扣账；P6 必验 |
| B17 | 两人并发占最后名额、替补到期/退出、无账号同名参与人；容量不超额，候补确认独立，姓名不自动合并，幂等及校验有证据 |
| B18 | 改交接清单后旧确认失效、撤销角色与委托分别执行、未授权者登记正式授权；不绕过接收/赋权审批，家庭关系保留；consent.record 独立检查，正式授权说明变版须重新核验 |
| B19 | 有答复后切换原生/外部采集源，活动取消同时有上级任务/费用；管理者预览迁移并版本化；普通家长不能改整项来源；必要权限不全时不部分生效 |
| B20 | 手动/自动/跨班/摘要/UNKNOWN 同时消耗发送额度，数据库恢复后重试；使用同一日预算与幂等键，未知保守占位，变更与普通分桶，停催只看最新账本 |

原型验收是静态模拟交互验证；正式上线须用 CloudBase/真机执行上述场景，不能以原型页面表现代替服务端事务与权限测试。
