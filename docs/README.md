版本 0.2 · 2026-09-08 · 需求与架构基线，尚未实施。

## 产品目标

老师和家委会只需发布一次，系统按学生范围通知已审批的亲属，跟踪采集和待办完成情况，并通过共同维护的知识库回答家长问题。

## 已明确的主线

1. 加入时必须选择身份，可以多选：系统管理员、老师、家委会委员、普通家长。
2. 可将成员设为管理员账户；系统管理员、老师、家委会委员默认具有管理员权限；权限层级为系统管理员 > 老师 > 家委会委员。
3. 三类管理身份共同维护班级学生名单、发布任务、维护知识库。
4. 老师、家委会委员、普通家长均可选关联自己的孩子，填写妈妈、爸爸、奶奶等亲属关系，关联由家委会委员及以上身份审批。
5. 通知范围支持女生、男生、全体、个人多选和自建群组，通知学生已关联亲属。
6. 信息采集可关联外部腾讯文档并产生通知；待办可关联其他任务，亲属点击完成前，在截止前持续按计划提醒。
7. 家委会线下或微信转账代收费用，小程序核对登记，并在班内逐学生公示缴费状态及金额、费用使用和结余。
8. AI 依据有效通知、学校活动和解释知识回答家长问题。

## 实施口径

本文档将用户明确需求与补充设计默认值分开。默认值可在开发前修改；未核验的平台能力不得按已具备实施。

尤其需要区分：身份申请与身份授权、管理员账户与系统管理员角色、学生任务完成与亲属个人完成、站内提醒与微信订阅消息、打开外部文档与实际提交。
