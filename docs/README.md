# 微信群家委会智能维护系统文档

本目录描述一套面向班级家委会的本地化微信群维护系统。系统使用独立微信测试账号，通过微信网页版和浏览器插件采集指定群消息；使用 DeepSeek Harness 编排 Agent；使用本地 Qwen3.8-27B 6-bit 视觉语言模型理解文本、图片和文件；使用部署在群晖 NAS 上的知识库、任务系统和审计系统支撑长期运行。

## 当前核心决策

| 决策项 | 当前选择 |
|---|---|
| 微信接入 | 微信网页版 + 自研浏览器插件 |
| 微信账号 | 独立测试账号 |
| 可读群 | 学校家长群、家委会群白名单 |
| 可写群 | 仅家委会群白名单 |
| Agent框架 | DeepSeek Harness |
| 主模型 | 本地 Qwen3.8-27B 6-bit，保留视觉能力 |
| 发送决策 | Agent直接决定 `SEND / DEFER / IGNORE / ESCALATE_PRIVATE` 等动作 |
| 执行保护 | 宿主只做目标白名单、Schema、幂等、限速等机械约束 |
| 事实库 | PostgreSQL |
| 中文全文检索 | PGroonga |
| 向量检索 | pgvector |
| 文件存储 | 群晖内容寻址文件目录 |
| 运行位置 | 群晖 Docker 承载后端；常开电脑承载微信浏览器；模型运行在具备足够内存的本地主机 |

## 设计原则

1. 原始消息、正式知识、Agent记忆相互分离。
2. 老师消息只有经过身份绑定后才能成为权威事实。
3. 通知不得被覆盖，修改、延期、取消以版本关系保存。
4. Agent拥有是否回复和回复内容的语义决定权。
5. Agent不能突破工具权限、目标群白名单和幂等约束。
6. 每条自动发送内容必须可追溯到消息、图片或文件证据。
7. 学校家长群默认只读；家委会群允许受控自动回复。
8. 个案、隐私、收费和争议问题优先转私下沟通或等待确认。
9. 系统长期待命，但主要由短期任务、周期任务和突发事件驱动。
10. 不尝试绕过微信扫码、安全验证、验证码或账号限制。
