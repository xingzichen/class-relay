# 身份、管理员账户与权限

版本 0.6 · 2026-09-10。用户已确定角色层级和关联审批门槛；授权流程、同级协作及本轮统一规则已采纳；未单独指定的技术参数保留为实施默认。

## 1. 三个独立概念

1. **身份角色**：系统管理员、老师、家委会委员、普通家长，可多选。只有已授权角色参与鉴权。
2. **管理员账户**：管理入口和明确的管理能力授权。系统管理员、老师、家委会委员默认获得相应能力；其他成员可被授予班级管理能力，不因此成为系统管理员或家委会委员。
3. **亲属关联**：账户与孩子的已审批关系，称谓为妈妈/爸爸/奶奶等，与管理身份独立。

管理员状态不能仅用一个无限授权的 `is_admin` 布尔值实现。服务端计算 `can_manage` 用于显示入口，实际操作逐项校验角色、授权能力和作用范围。

## 2. 角色及作用范围

| 角色 | 层级 | 范围 | 默认能力 |
|---|---:|---|---|
| 系统管理员 | 300 | 当前系统实例全局 | 全部班级管理范围、配置、身份与权限授予（私有财务另需职责指派） |
| 老师 | 200 | 被授予的班级 | 学生、任务、知识、课程/值日、活动、交接、正式授权核验、本班下级管理 |
| 家委会委员 | 100 | 被授予的班级 | 学生、任务、知识、值日、活动、交接草稿；课程须委托 |
| 普通家长 | 0 | 自己已审批关联的孩子及获准班级公共内容 | 查看、问答、亲属回执 |

同一人可在 A 班是老师，在 B 班是普通家长，A 班管理权限不得扩展到 B 班。系统管理员是全局角色；其余角色绑定班级。有效全局管理员执行管理操作不依赖逐班入班；其他角色及委托能力依赖对应班级正常成员关系。亲属回执一律检查本人有效孩子关联，不能借全局角色代点。未获授权的入班申请仅能看申请和公开加入说明。

## 4. 身份申请与授予

- 加入时选角色只是申请，不能把客户端上传的角色直接写成已授权。
- 系统管理员审核系统管理员和老师申请；系统管理员或本班老师审核家委会申请；三类管理身份可审核普通入班申请。
- 授权者可直接赋予自己有权授予的角色，记录来源为“直接授予”，不要求被授予人重复申请。
- 申请者不得审核自己申请的任何管理身份或孩子关联；并发审批通过条件更新只允许一个有效终态。
- 首位系统管理员使用部署时一次性初始化流程绑定经验证的账户，不采用“第一个注册者自动成为管理员”。完成后关闭初始化通道。
- 系统管理员可管理同级，但不能撤销最后一位有效系统管理员；老师不能管理老师/系统管理员身份；家委会委员不能授予管理身份。

## 5. 将普通成员设为管理员

默认由系统管理员或本班老师操作“设为管理员”，选择班级和能力集，可附有效期。能力包括 `student.manage`、`group.manage`、`task.publish`、`task.manage`、`task.review`、`knowledge.manage`、`report.read`，以及第 10、11 节的日程、活动和交接能力；另可按第 8 节授予独立财务能力集，必须明确选择，不能隐式全选系统能力。

普通成员发布任务/知识的权威层级上限为家委会层级；课程和值日属于班级共享安排，按显式日程能力维护，不沿用原任务发布者的层级锁定。不得授予角色管理、再次委托、系统配置或孩子关联审批。若需要审批孩子关联，须由有权者正式授予家委会委员及以上角色。这保持用户提出的审批身份门槛。

老师只能授予其默认或有效委托具备的业务能力；财务职责的指派由角色管理权限单独允许，但不赋予指派者实际记账/复核或私有读取权，也不能通过自定义管理员授权修改同级/上级内容。角色或授权撤销后即时失效，既有会话不能继续依靠旧权限。撤销委托只去掉委托能力，不去掉账户仍持有的角色默认能力；停用账户阻断全部访问。

## 6. 层级与共同维护

- 学生名单与学生群组属于班级共同资源，三类管理身份可以协作维护，不按最初创建者锁定。
- 任务与知识的权威层级在发布时记录。系统管理员可管理全部；本班老师可管理老师及以下内容；本班家委会委员可共同编辑家委会层级内容。
- 下级修改上级内容走“修订建议”，由相应权限人员确认发布。协作不能无痕覆盖原版本。
- 受委托管理员仅在显式授权内操作，发布权威层级为家委会业务上限，但作者身份仍显示原身份及“受委托管理员”，不能标成老师。
- 管理者角色变更不自动改变已发布内容的权威层级；有相应对象管理权限者可重新指派 owner_id，接收者无权直接改写的上级内容仍走修订建议，留审计。
- 权限层级用于管理操作，不用于推断通知内容真伪。来源矛盾由管理者维护知识版本，AI 暂不作确定结论；不产生人际冲突处理或家长反馈流程。

## 7. 亲属审批与数据可见性

申请人不能审批自己与孩子的关系，包括“老师＋家长”和“家委会委员＋家长”。同一家庭其他合格审批者可处理；是否追加亲属回避规则暂不扩展。

通过后才能接收和处理孩子任务；待审批、拒绝、撤销关系均不授予访问。内容阅读范围独立于处理对象：CLASS_PUBLIC 面向正常入班且关联在班孩子的家庭和已授权本班管理者；TARGET_PRIVATE 面向当前目标孩子的有效关联家庭及有权管理者。非目标家庭可读获准公共说明，但不承担回执或收到催办。亲属称谓更改默认重新审批，原有效称谓在审批通过前继续有效；解除关联立即生效并取消相关队列。

家长不获得学生管理名册访问权。普通任务按学生完成模式只显示自己孩子的完成情况和处理者必要称谓。费用公示按第 8 节另行开放班内逐学生姓名、缴费状态与金额，不开放其他家庭私有信息。管理者只在职责所需的班级内查看名单、审批和统计。

## 8. 费用权限扩展

系统管理员、老师、家委会委员在各自范围内可维护费用事项与公开说明；实际经办、复核、公示发布及原始凭证读取须经有权者显式指派财务职责，角色默认不开放全部原始凭证。经办与复核必须是不同账户，最高层级也不绕过禁止自复核和已入账不可覆盖规则。普通委托管理员默认不含财务能力，需要单独授予财务能力集。

本班已正常加入且关联在班孩子的家长可查看班内已发布的逐孩子缴费状态及金额、支出和结余；这是用户明确要求的班内公示，不开放其他孩子私有任务、亲属联系方式或原始交易凭证。全部规则见[费用权限](finance.md)。

## 9. 服务端鉴权顺序

账户有效 → 班级成员/全局角色 → 已授权角色和委托能力 → 对象所在班级 → 内容管理层级或亲属关联 → 对象状态/版本 → 执行并记录审计。

客户端隐藏按钮只是展示逻辑，不能替代 API、附件访问和 AI 检索的服务端权限校验。

## 10. 日常安排权限

课程表默认由系统管理员和本班老师维护；家委会可维护值日表，课程维护如需委托由有权者显式授予 `schedule.course.manage`。值日维护可单独授予 `schedule.duty.manage`。跨班串课需对涉及班级均有课程权限，否则拒绝整体调整；不得只提交其中一侧。学生值日名单是用户要求的班内安排展示，详见[日常安排权限](schedules.md)。

## 11. 能力目录与交接授权

| 能力 | 范围与动作 | 默认及授予规则 |
|---|---|---|
| schedule.course.manage | 编辑、预览、发布、修订、撤销课程安排 | 系统管理员/本班老师默认；两者可显式授予本班合格成员；跨班操作需同时覆盖各班 |
| schedule.duty.manage | 编辑、发布、修订、撤销值日安排 | 三类管理身份默认；系统管理员/老师可委托 |
| activity.manage | 管理活动、报名入口、志愿岗位、名额、取消与物资清单 | 三类管理身份默认；系统管理员/老师可委托，不含财务记账或正式授权 |
| finance.record / review / publish / read_private | 分别对应经办、入账复核、公示发布、职责内原始材料读取 | 所有人均须显式指定；系统管理员/本班老师依角色赋权权限指派，指派本身不含实际执行权限；本人不可自复核，权限指派留审计 |
| consent.record | 记录学校原渠道正式授权核验状态，不执行签署 | 系统管理员/老师默认；其他人须显式委托，不含在 activity.manage 内 |
| handover.manage | 建立、盘点和提交交接草稿 | 三类管理身份默认；可委托整理，不授予角色管理权 |
| handover.activate | 按接收确认结果切换职责并撤销列明的旧授权 | 仅系统管理员或有权本班老师，不能通过 admin_grants 委托；逐项验证赋权/撤权范围 |

交接接收人确认清单不等于自动提权；新授权由有权者审批。业务维护人变化不改变发布内容权威层级。旧委托、旧管理角色、普通家长角色和孩子关联分别处理，不能一键误删家庭资格。完整流程见[协作与交接](committee-workflows.md)。

### 离班家庭资料

正常账号即使已离班，仍可提交本人历史关系的资料取得申请；由有权管理者核验历史关联，只生成本家庭脱敏缴费记录。审核属于管理操作，不是投诉工单。没有有效账号或无法核验的，由学校既有渠道处理，不能自动恢复原班公共读取；资料令牌、到期及文件读取单独鉴权。

## 12. 变更告知专用权限

任务移出、值日换人或活动取消后，原对象的催办与私有任务访问失效；独立变更告知仅保留该家庭相关的取消/移出结果。发出及读取时仍需账户、班级、原孩子有效关联；撤销关联、离班或停用不因旧收件快照而被绕过。已完成家庭可收到必要变更，不要求其重新完成。班内公共原文按公共阅读资格另行判断。
