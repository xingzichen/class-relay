# 腾讯云开发能解决到什么程度

版本 0.6 · 2026-09-10。业务覆盖按当前统一规则更新；平台依据为 2026-09-08 已查阅的官方资料，尚未连接用户云账户或部署验证，本轮没有重新核验平台能力或价格。

## 1. 结论

腾讯云开发可以作为这套小程序的完整应用后端：无需自建服务器即可承载身份、任务和表单、活动及志愿报名、课表值日、费用账本及公示、维护交接、知识库和 AI。业务范围内暂未发现必须增加其他后端厂商才能实现的模块。

它提供运行、数据、文件、调度和模型调用能力，并不会自动生成家委会业务规则。角色层级、亲属审批、原生与外部来源、成人名额、串课、授权交接、缴费核对、对账和 AI 语气红线仍需开发与验收。

最明确的外部边界是：微信不保证任意频次持续推送；腾讯文档跳转/提交回传需实测；线下资金到账仍靠人工核对；AI 可以约束和评测，但不能承诺永远无误或代替人工处理敏感事项。

## 2. 按模块判断

| 需求 | 可支持程度 | 还需完成什么 |
|---|---|---|
| 微信身份和登录上下文 | 平台提供基础能力 | AppID/环境绑定，角色与班级权限由业务实现 |
| 多角色、管理员委托、孩子审批 | 可以完整实现 | 云函数鉴权、引用约束、禁止自审、状态和审计 |
| 通知、作业、准备清单、模板 | 可以完整实现 | 模板/实例、发布范围、版本、站内收件与回执 |
| 待办及持续调度 | 站内和调度可实现 | 持久计划、幂等、跨班共享预算、家庭偏好；旧催办失效与独立最小变更告知分开 |
| 微信服务通知 | 有条件支持 | 真实模板和用户授权；CloudBase 不增加订阅权限 |
| 课程表、值日表、串课/临时调整 | 可以完整实现 | 基础周表、日期例外、教学日历、双方一致性与提醒联动 |
| 线下缴费登记及逐学生公示 | 可以完整实现 | 显式财务职责、人工核对、双人复核、追加账本、公示审核发布；最新入账停催不等公示更新 |
| 自动判定实际线下到账 | 不直接提供 | 截图和“我已缴费”不能替代真实流水核对 |
| 支出、退款、剩余和对账 | 账目层可完整实现 | 实际收付款在小程序外发生，云端登记并核对 |
| 腾讯文档跳转采集 | 有条件支持 | 目标产品、主体、跳转参数/业务域名实测；首版自报加核验 |
| 原生简单表单与采集换源 | 业务可实现 | 每孩子/轮次版本、已答复停催；每表唯一来源，有答复换源需管理权限与迁移清单 |
| 成人志愿者代报名 | 业务可实现 | 实际成人可无账号/订阅；关联家长代填，稳定参与人去重、事务容量、候补邀请确认；外部自报须核验 |
| 活动关联与整体取消 | 业务可实现 | 完整影响清单、各关联对象授权及单一有效修订；已收费用留待处置，不自动退款 |
| 维护、换届与旧权撤销 | 业务可实现 | 未完成事项/知识/活动/日程/财务清单、接收和赋权分离、预备授权不可用、整体生效与历史保留 |
| 正式监护人授权 | 仅承载必要核验记录 | 沿用学校渠道，consent.record 独立授权；普通回执不等于正式授权，不提供电子签署 |
| 离班本家庭历史资料 | 业务可实现 | 核实历史关联、限定本人家庭范围、脱敏和限时导出，不恢复全班阅读 |
| 轻量物资清单 | 业务可实现，正式交付 P6 | 认领/领取/归还/保管与数量一致；关联支出不自动扣账 |
| 腾讯文档自动提交同步 | 尚未确认 | 官方 API/授权/身份映射与回调验证，不计入首版已具备 |
| 公共知识库与混元问答 | 平台提供生成与检索基础能力，业务可实现 | 按[腾讯云 AI 实施设计](ai-cloudbase-design.md)完成授权检索、ai_eligible、事项/活动身份、来源版本/有效期、维护交接、缓存失效、输出校验和 AI01—AI21 评测 |
| AI 不指责、不泄露、不承诺 | 可通过多层约束降低风险 | 不能承诺零误答；失败回退中性模板，版本上线需红线用例通过 |
| 反馈、投诉、冲突、敏感个案 | 产品明确不做 | 不建工单、不追问或代转达，提示原有人工渠道 |
| 备份、监控、成本控制 | 平台提供基础能力 | 集合回档、文件归档、恢复演练、用量和告警配置 |

“可以完整实现”指能力适配，不代表已经有现成模块或已部署完成。

## 3. 哪些部分省掉运维，哪些仍需编程

可以省去自建 API 服务器、家庭穿透、数据库进程、文件服务和常驻定时进程的运行维护。客户端通过云开发 SDK 调用函数及文件服务，云端按请求/触发运行。[云函数调用](https://docs.cloudbase.net/recipes/add-cloud-function-wechat-miniprogram)、[函数与定时配置](https://docs.cloudbase.net/cli-v1/functions/configs)

业务仍要编程：每班的角色范围、孩子关系、多亲属完成粒度、课表变更版本、费用分摊和对账、AI 输入输出规范。文档数据库支持服务端事务，但批量分发需小事务与异步作业设计，不能照搬关系库的超大事务。[事务说明](https://docs.cloudbase.net/database/transaction)

## 4. 预算判断

2026-09-08 查询时官方页面显示个人版限时 19.9 元/月、标准版 199 元/月及免费体验版；这是历史价格记录，开通前须按实际账户、环境数量、模型能力与用量重新核验。不能确认每月 19.9 元就能覆盖开发、生产、备份、全部附件和 AI。[官方价格](https://tcb.cloud.tencent.com/pricing)

建议先用模拟班级验证用量和平台限制，再确定套餐；真实家庭数据与正式财务运行不能依赖未验证的免费额度。AI 通过 CloudBase 的腾讯混元能力接入，模型开关与具体版本以环境支持为准。[AI 服务端接入](https://docs.cloudbase.net/ai/model/nodejs-access)

## 5. 原型与实施边界

原型展示产品界面、角色视角和本地模拟状态，使用虚构班级、学生及账目。原型中的“确认”“审批”“发布”等交互不会调用云开发、发送微信消息、变更实际账本或转达问题，不作为真实后端能力验收。

原型问答使用本地预设答案演示语气和引用，不是真实模型，也不代表生产安全校验已经实现。已在浏览器检查移动窄屏及明暗外观，并验证待办完成、通知范围预览与发布、串课结果、缴费复核后生成、审核发布公示再切换金额和问答边界等主要交互。

原型还模拟原生答复、成人代报名、候补与外部核验、活动取消、正式授权分离、最新账本停催、每日两次催款及忽略提示、负责人交接与撤销旧授权、物资认领归还。已有 [44 项交互断言及窄屏检查记录](../原型图/tests/verification.md)；本轮仅对齐文档，未重跑交互或真实环境测试。

原型中的模式切换/时间推进属于演示控制，不构成普通家长可变更整项表单来源或跳过真实间隔的生产权限。完整能力包括跨班并发预算、容量、授权切换、迁移和恢复，正式实施按[实施计划](implementation-plan.md) P0—P6 分期验收。
