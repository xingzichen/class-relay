# 腾讯云开发可行性与上线验证

版本 0.6 · 2026-09-10。应用后端全部使用腾讯云开发已由用户确定；本次仅更新文档，尚未开通环境、购买套餐或部署函数。

## 1. 结论

身份、学生、亲属审批、任务表单、活动/代报名、课程/值日、正式授权核验、费用公示、维护交接和公共知识库统一由 CloudBase 云函数、文档型云数据库与云存储实现；定时云函数负责持久提醒，CloudBase AI 接入腾讯混元。无需先验证家庭服务器或穿透链路。

优先验证云开发环境关联、真实微信身份、服务端事务、存储权限、定时任务恢复及模型开通。微信重复推送权限、腾讯文档跳转仍由对应平台规则决定，不因使用 CloudBase 自动获得。

## 2. CloudBase 技术验证矩阵

| 验证项 | 通过证据 | 失败时处理 |
|---|---|---|
| 环境及 AppID 关联 | 微信开发者工具和真机调用指定环境函数，取得正确 APPID/OPENID | 纠正绑定与接入模式，不改用客户端自报身份 |
| 调用来源隔离 | 小程序函数、定时内部函数分开，普通用户不能调用内部处理入口 | 调整权限和函数入口，禁止参数模拟内部身份 |
| 数据库模式/SDK | 文档型数据库、选定服务端 SDK 的小事务在目标环境工作 | 固定兼容版本，按实际容量缩小单次操作 |
| 并发与幂等 | 两次审批只生效一次，重复记账无重复实收，超时重领无覆盖 | 使用确定性 ID、事务复核、租约和尝试标识 |
| 大范围分发 | 超过单事务容量的收件人能分批完成，中断续跑可对账 | 持久游标和不可变快照，不能依靠一个长事务 |
| 数据安全规则 | 前端直接查/改核心集合被拒绝，云函数能按业务权限操作 | 默认拒绝直连，逐入口补齐权限 |
| 文件安全规则 | 跨用户上传/覆盖/列举被拒绝，私有凭证不能凭 fileID 读取 | 授权上传会话、受控下载和脱敏副本 |
| 定时触发 | 验证配置时区、频率、重复触发、函数超时和租约恢复 | 调整批量上限，保存状态后继续，未知外发不盲重试 |
| AI | 混元可调用，公共知识过滤、来源引用、语气红线与越界不受理用例通过 | 调整策略/模型版本；失败回退中性模板或原文 |
| 日常安排 | 周期表、指定日期串课/换值日、双方生效与旧提醒失效 | 修订号、日期覆盖、原子生效与幂等补偿 |
| 采集与换源 | 原生答复和外部自报来源不同，普通家长不能改全表来源；有权管理者迁移旧答复并版本化 | 固定当前来源并保留历史，不同时双写计数 |
| 志愿容量与代填 | 无账号成人可代填，同名不自动合并；并发最后名额不超额、候补预留与确认/过期一致 | 核验稳定参与人、确定性唯一键和容量事务 |
| 活动取消 | 任务/日程/报名/费用权限齐备后同一修订生效；越权或版本变动不部分提交 | 保持原状态，形成待有权者处理的影响清单 |
| 授权交接 | 改清单使旧接收失效，接收不提权；预备授权不可用，生效旧指定授权立即失效 | 阻止生效并修复授权/版本，不靠后台慢慢撤权 |
| 正式授权与家庭资料 | consent.record 独立检查；报名不自动核验；离班导出仅本家庭且链接限时 | 停用不合格入口，保留学校原有正式授权渠道 |
| 财务公示与停催 | 有界事务入账，生成 READY 快照后人工审核发布；最新账本停催、自报仅暂停，跨项目催款每日最多两次 | 不显示半份公示，不用旧快照催已缴家庭，不以自报增加实收 |
| 共享消息预算 | 手动/自动/跨班/摘要同用四次总量、普通两次/变更两次/催款两次；间隔、免打扰、UNKNOWN 占额一致 | 未能证明共享预算时停止相关外发，站内保持可用 |
| 物资（P6） | 数量、认领、领取和归还可追溯，关联支出不重复入账 | 纠正事件/幂等，不以 P5 完成视作本项交付 |
| 恢复 | 回档与文件版本清单在隔离云环境核对，账本、公示、交接后有效授权、报名容量及当日发送预算相符 | 补齐备份/归档措施后再试用 |

2026-09-08 已查阅[小程序调用云函数](https://docs.cloudbase.net/recipes/add-cloud-function-wechat-miniprogram)、[事务](https://docs.cloudbase.net/database/transaction)、[触发器配置](https://docs.cloudbase.net/cli-v1/functions/configs)、[AI 服务端 SDK](https://docs.cloudbase.net/ai/model/nodejs-access)。这些资料验证方案所需能力存在，不代表用户具体环境已经通过测试。

## 3. 微信订阅消息

持续提醒先表现为业务计划和站内消息，微信实际外发必须满足用户授权、模板类型、额度和平台规则；没有订阅不阻止关联家长在站内代报名。家庭主要接收人只影响外发，逐亲属确认逐人处理，志愿事项只发有效代填责任人。

业务默认同接收人跨班每日总量四次，普通初发/周期/催款合计两次、必要变更两次，催款另有两次子上限；两小时间隔，22:00—08:00 免打扰。手动/自动/摘要/重试共享预算，UNKNOWN 保守占位；独立变更告知按自身有效期和资格检查，不能被旧任务“已完成”一律拦截。真机验证同时覆盖这些业务限制。

| 验证 | 需保存的结果 |
|---|---|
| 主体/类目/认证 | 实际小程序后台配置和可用业务范围 |
| 模板 | 通知/任务场景匹配的模板 ID、字段、类型和规则 |
| 云调用 | 目标 CloudBase 环境内发送成功/失败及错误码，定时触发也能绑定正确 AppID |
| 用户授权 | 主动订阅、拒绝、撤销及授权不足时的真机行为 |
| 重复提醒 | 同一用户多次提醒的实际发送能力，不能仅凭教育类目假定有长期模板 |
| 状态区分 | 接口接受、详情打开、确认/完成分别保存 |

此前微信订阅官方页面读取失败，完整当前规则仍需在微信后台及真机确认。CloudBase 的云调用不突破微信限制。

## 4. 腾讯文档与备案边界

用户所称腾讯云文档暂按腾讯文档/收集表理解。用实际测试链接验证官方支持的小程序跳转、符合条件的 web-view 或复制链接指引；页面是否可打开、登录与返回流程都要真机验证。打开不算提交；仅外部模式采用亲属自报与人工核验。原生简单表单由站内提交直接记录来源和答复；每表单只用一个当前来源，已有答复的换源须由管理者核对迁移和版本。外部志愿报名不自动占名额，人工核验参与人/岗位容量后才确认或进入候补。

云开发 SDK 承载核心业务后，不把 giraffee.top 的域名备案或自建 API 域名列为上线前提。小程序自身备案、主体和类目审核仍需完成；若外部文档使用 web-view，则另核验主体资格和业务域名要求。选择云开发不能代替外部域名控制权或文档访问权限。

2026-09-08 腾讯文档开放平台入口可访问，但尚未确认目标产品、跳转参数或提交回调；微信 web-view 官方页面此前读取失败。

- [腾讯文档开放平台](https://docs.qq.com/open/document/)
- [微信 web-view](https://developers.weixin.qq.com/miniprogram/dev/component/web-view.html)

## 5. 费用模块

第一版已确认在线下/微信转账收款，云开发只承担核对登记、班内逐学生缴费公示、支出、退款和结余，无小程序支付接入依赖。费用事实和权限以[费用规范](finance.md)为准。

未来若增加小程序支付，应继续通过 CloudBase 内的独立服务端适配接入官方支付，先验证认证主体、商户/AppID 绑定、回调验签、查单、退款与对账，不使用前端成功提示作为入账凭据。[微信支付接入准备](https://pay.wechatpay.cn/doc/v3/merchant/4015459512)

异步核对依赖实际经办人同步：展示未核对/未复核/待公示与最后同步时间；最新账本核实后停催，自报已交暂停但不增加实收。每条催款含“款项同步可能有延迟，如果已交款请忽略。”交接如实移交未核对款项、差异、退款/结余处置和公示版本；交接完成不等于资金已核对。

实际收费依据、参与安排、代收和独立复核负责人由班级运营方确认；应用内部复核不等于学校批准。本次不发起任何收费或交易。

## 6. 成本与资源预算

截至 2026-09-08 查询，CloudBase 官方页面展示免费体验版、个人版限时 19.9 元/月、标准版 199 元/月。适用环境、权益和下单价格需以实际账户为准，不能把单环境价格当作整个系统预算。[CloudBase 官方价格](https://tcb.cloud.tencent.com/pricing)

预算需包括：

- 开发、生产和拟用隔离备份环境各自套餐与额度；免费环境数量有限，不能假定所有环境免费。
- 云函数执行、文档数据库读写、索引、文件存储与下载等资源消耗。
- 定时扫描和每班学生/亲属展开量；通过索引、分页和合并消息控制消耗。
- CloudBase AI 资源用量、日志、备份/归档、恢复演练成本。
- 小程序认证/年审等平台费用，按实际主体核对。

套餐内额度与超额计费应分别核对，避免重复预算；原“复用 NAS 后端近零新增费用”的估算已被本次选型取代。不需要为核心接入另外购买云服务器或自有域名。先以模拟班级压测估算用量，设置预算告警、AI 次数上限和作业批量上限，再确定正式套餐。

## 7. 备份和正式试用门槛

按实际套餐验证文档数据库备份/回档时间、保留期及云存储独立归档策略。数据库回档生成新集合，不会自动恢复附件全部历史；必须核对同一账本修订、公示版本和文件清单后切换。[数据库回档](https://docs.cloudbase.net/database/backup)

真实班级试用前完成：多角色加入、亲属审批、定向/公共阅读、订阅拒绝回退、完成停催及变更告知、原生/外部答复、代报名与候补、活动整体取消、正式授权核验、知识维护/引用、费用核对与逐学生公示、交接撤权和本人家庭资料。上线证据包含越权、重复触发、事务冲突、文件私有访问、共享消息预算和恢复，不能以控制台“部署成功”替代。

运营方须补齐每个孩子至少一名有效关联家长的覆盖；异常孩子保留待处理状态，不虚构关系或通知成功。确认活动与知识维护人、表单当前来源及文档访问范围、独立财务经办/复核/公示职责、正式授权核验人员、交接接收与撤权清单，以及数据告知和保留期。

恢复先暂停外发和无法确认权限的管理操作，核对备份点后的撤权/交接审计，不能恢复旧人的管理权；重建当天预算与发送记录，未知结果保守占位，无法重建剩余额度则当天不补发。报名容量、最新账本和公示截止也必须对应同一有效业务版本。

P5 联合门槛为 A01—A30、B01—B15/B17—B20、S01—S15、F10/F11、AI01—AI21；P6 物资另须 B16。具体用例见[实施计划](implementation-plan.md)。原型已有本地模拟验证，以上均须 CloudBase/真机和运营证据，当前尚未执行。
